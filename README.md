# Shopping Store – PHP & MySQL

Shopping Store est une application web de commerce électronique développée avec **PHP**, **MySQL**, **HTML5**, **CSS3** et **JavaScript**. Elle offre une expérience d'achat simple et intuitive, permettant aux utilisateurs de parcourir les produits, de rechercher des articles, de les ajouter au panier et de passer des commandes en ligne.

L'application comprend également un espace d'administration sécurisé permettant de gérer les produits, les catégories, les utilisateurs et les commandes. Les données sont stockées dans une base de données MySQL, garantissant une gestion fiable et performante.

## Fonctionnalités principales

* Inscription et authentification des utilisateurs
* Catalogue de produits avec images et descriptions
* Recherche et filtrage des produits
* Gestion des catégories
* Panier d'achat
* Passage de commande
* Tableau de bord administrateur
* Gestion des produits (CRUD)
* Gestion des catégories (CRUD)
* Gestion des commandes
* Interface responsive adaptée aux ordinateurs, tablettes et smartphones

## Technologies utilisées

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* Bootstrap
* XAMPP

## Objectif du projet

Ce projet a été réalisé afin de mettre en pratique le développement d'une application web e-commerce en utilisant PHP et MySQL. Il met en œuvre les opérations CRUD, l'authentification des utilisateurs, la gestion d'une base de données relationnelle et la création d'une interface utilisateur moderne et responsive.
